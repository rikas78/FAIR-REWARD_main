# FairReward 2.0

Production rewards platform built around real provider inventory, server-side conversion validation, reward ledger, wallet, payouts, adaptive planning and analytics.

## Product surfaces
- Promotional: public-facing brand and acquisition experience.
- Platform: authenticated FairReward experience using the same production core.

The promotional and platform experiences share the same core architecture, provider integrations, data model and reward logic.

## Core principles
- Click is not a reward.
- Provider conversion/postback is authoritative for reward creation.
- Financial movements are ledgered and auditable.
- Idempotency is mandatory for conversions, rewards, reversals and payouts.
- No secrets in source control.
- Real provider data wherever available.
- Analytics and event collection are designed from day one.
